# Simulation documentation

## Tool

Cadence Virtuoso

## Available evidence

The `images/` directory in the repository contains screenshots of:
- The complete 8-bit asynchronous counter schematic
- The NAND-based master–slave JK flip-flop implementation
- Three transient simulation output plots showing the clock and counter outputs (`I00` to `I07`)

## Native project files

The original Cadence Virtuoso schematic, testbench, model files, and simulation state are not currently available in this repository. Therefore, the simulation cannot be reproduced from this repository alone.
